Baselines

Recordemos qué significa cada métrica
- MAE: error absoluto promedio. Nos dice cuántas unidades nos equivocamos, en promedio. Cuanto menor, mejor.
- MASE: compara el error del modelo con el de un pronóstico Naive de referencia. Si es menor que 1, supera esa referencia; si es mayor que 1, tiene peor desempeño.
- Sesgo: promedio del error con signo (Pronóstico - Real). Positivo significa que sobreestimamos; negativo, que subestimamos.

Mi recomendación es que no usemos exclusivamente Naive como modelo de referencia. Lo usaría como referencia universal para calcular MASE, pero seleccionaría el mejor baseline por SKU durante validación y exigiría que los modelos más complejos demuestren una mejora frente a él.

Escala definida: Representa el error medio absoluto (MAE) que obtendría un pronóstico simple donde cada predicción es igual al valor del período anterior. Nos indica cuánto suele variar la demanda de un mes al siguiente, en promedio

El MASE (Mean Absolute Scaled Error o Error Absoluto Escalado Medio) es una métrica estadística que evalúa la precisión de un pronóstico comparándolo contra un método básico de referencia.
Responde de forma directa a una pregunta clave: ¿El modelo predictivo realmente aporta valor frente a no hacer nada sofisticado? Mide de forma justa si la complejidad añadida justifica su uso frente a una línea base (baseline) sencilla.
MASE no mide si Naive tiene un error de 1. Mide cuánto error comete un modelo en relación con el error histórico de Naive. Si el MASE del Naive evaluado es menor que 1, significa que durante ese período de evaluación Naive tuvo un error menor que su propio error histórico de referencia.

El cálculo divide el error absoluto medio (MAE) de tu modelo entre el error absoluto medio de un pronóstico ingenuo dentro de la muestra histórica (asumir que el mes que viene se venderá exactamente lo mismo que en este mes)

o MASE < 1. El modelo es mejor que el pronóstico ingenuo.

o MASE = 1. El modelo tiene exactamente el mismo desempeño que el método ingenuo.

o MASE > 1. El modelo es peor que el pronóstico ingenuo. En este caso, conviene descartar el modelo y usar simplemente el último dato conocido como predicción.
